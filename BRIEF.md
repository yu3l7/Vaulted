# BRIEF — Vaulted

Single-page Fortnite digital products shop. Minimalist (option B from the scoping questions), Discord-first contact.

## Audience

Buyers looking for Fortnite digital goods: stacked accounts, V-Bucks, rare skins, boosting, coaching, and configs. Mostly 16–30, know what they want, judge on proof and response speed.

## Routes

Single page, anchor-linked sections:

- `/` — **Persuade** — full landing page
  - `#top` — Hero
  - `#products` — Featured products (6)
  - `#pricing` — 3 tiers
  - `#process` — How it works (3 steps)
  - (no id) — Vouches / social proof
  - `#faq` — FAQ
  - `#contact` — Final CTA

Plus:

- `/sitemap.xml`, `/robots.txt`, `/opengraph-image` — generated by Next conventions
- `/not-found` — custom 404

## Content

**Provided:** none — all placeholder, realistic lorem-grade.
**Partial:** none.
**None (placeholders needed):** Discord invite, email address, prices, product names, vouches, FAQ, stats. All in `src/lib/content.ts` — edit in one place.

## Brand

- **Name:** Vaulted (proposed; "vaulted" is the Fortnite term for rare-removed items)
- **Tagline:** Curated Fortnite supply. Verified. Delivered.
- **Font:** Inter (one family, two weights via `next/font`)
- **Colors:**
  - bg: `#fafafa` light / `#161616` dark
  - fg: `#2e2e2e` light / `#f5f5f5` dark
  - accent: indigo/violet `oklch(0.58 0.20 270)` — restrained, gaming-adjacent
  - 5 tokens total
- **Tone:** Direct, confident, no marketing fluff. Numbers up front (4,200+ orders, 18 min median, 4.9★).
- **Constraints:** Minimalist — no neon, no gaming tropes beyond the subtle accent. No images. No emoji beyond ◆.

## Stack

- Next.js 16 App Router + TypeScript strict
- Tailwind v4 (CSS-based config via `@theme inline`)
- `next/font` for Inter
- One client component: `MobileNav` (the only `use client` island)
- `prefers-color-scheme` for light/dark — no toggle
- Edge-deprecated OG image generator switched to `nodejs` runtime

## Discord contact

Placeholder invite: `https://discord.gg/vaulted` — replace before launch.

## Anti-patterns avoided

- No UI library
- No animation library
- No client components except the mobile drawer
- No `<img>` tags
- No arbitrary Tailwind values (all from `@theme`)
- No emoji decoration (only the diamond glyph)
- No carousel, no slider, no spinner
- No Google Fonts `<link>` (uses `next/font`)

## What's intentionally missing

- A `/products/[slug]` route (single-page is the brief)
- A real contact form (Discord is the channel)
- Theme toggle (prefers-color-scheme handles it)
- Search
- Pagination
- Auth
